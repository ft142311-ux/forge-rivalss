# Forge-Rivals — Read-only Season 2 Preflight v1

Добавляет отдельный диагностический модуль `src/app/actions/season-rollover-preflight.ts`.

## Гарантии
- Выполняет только чтение Firestore (`get` / запросы `get`).
- Не создаёт план перехода и архив.
- Не чинит слоты/таблицы/матчи.
- Не меняет `season_config`, не получает блокировку перехода и не публикует Season 2.
- Сохраняет контрольную дату `2026-10-08T15:00:00.000Z`.

## Подключение
Функция `inspectSeason2RolloverPreflight(db)` принимает уже созданный экземпляр Firebase Admin Firestore. Её можно вызвать из доверенного серверного диагностического действия/скрипта, передав существующий `getAdminDb()`.

Результат `safeToProceed: true` — необходимая, но не абсолютная гарантия: перед фактическим переходом всё равно должны пройти штатная блокировка, повторная проверка плана и финальная проверка готовности. Если любой пункт не пройден, `blockers` перечислит причины.

Примечание: проектные поля матча читаются с поддержкой нескольких распространённых имён. Если текущая схема хранит ранг/счёт в других полях, модуль безопасно покажет блокеры вместо изменения данных; сопоставление схемы следует проверить по актуальным документам перед использованием результата как разрешения на переход.
